What Sela does

One goal. Everyone can see it.
Nobody holds the keys alone.

Sela keeps a shared goal in a Solana program, not in a spreadsheet or one person's wallet. These are the three pieces, and where each one stands.

In build

Shared savings goals

Create a goal with a target, then let each member contribute USDC. The balance is read from the chain, so it is the same number for everyone.

In build

Recurring allowances

Authorize a weekly or monthly amount once. A keeper triggers each payment when it is due, and the on-chain rules cap it at the amount you approved.

In build

Passkey approvals

Contributions and withdrawals are approved with a device passkey. There is no seed phrase to hand to a family member, and each device is registered to the goal.

The payment engine

Built on a stack that already moves real USDC.

Every Sela payment goes through the Smart TX Stack, first built for invoicing and running on mainnet today. Goals and allowances reuse it instead of a plain wallet transfer.

Submitted as a Jito bundle with a live-market tip, and sent to a standard RPC at the same time.
An AI agent decides whether a stalled transaction should be retried, and at what tip.
Retries wait for the old blockhash to expire first, so a slow payment cannot be charged twice.
